# 補上 3.5.0 版「新功能！」公告內容

## 背景

`lib/whats_new/whats_new_content.dart` 的 `kWhatsNewContent` 到 `'3.4.0'` 為止就
沒有再更新,但 `pubspec.yaml` 已經 bump 過 `3.4.0` → `3.4.1` → `3.5.0`
(目前 `3.5.0+1`)。本次把 2026-09-18 當天合併的 5 個 commit 對應到
`docs/changes/` 既有的修改紀錄,補上 `'3.5.0'` 這個版本 key 的公告內容。

## 內容取捨

5 個 commit 裡,有 4 個是使用者回報的 bug 修正、1 個是真正的新功能。因為修正的
都是使用者原本就看得到、也回報過的錯誤顯示/行為(備註寫錯、分類顯示簡體、初始
資金沒有立刻反映、日曆「今天」跳錯週、轉帳看不出對象帳戶、跨幣別金額對不上),
比照這份清單過去也曾收錄「行為修正」類項目的做法,全部 5 項都寫進
`'3.5.0'`,而不是只收錄唯一的新功能:

1. **AI 記帳商家欄位 + 信用卡回饋自動套用**(新功能,見
   [2026-09-18-ai-bookkeeping-reward-autofill.md](2026-09-18-ai-bookkeeping-reward-autofill.md))
2. **轉帳補齊「轉出→轉入」帳戶顯示 + 修正跨幣別折算金額**(見
   [2026-09-18-transfer-direction-display-and-rate-fix.md](2026-09-18-transfer-direction-display-and-rate-fix.md))
3. **信用卡繳款轉帳備註/分類與網頁端一致**(見
   [2026-09-18-app-credit-card-payment-web-parity.md](2026-09-18-app-credit-card-payment-web-parity.md))
4. **編輯帳戶初始資金立刻反映**(見
   [2026-09-18-account-edit-initial-balance-stale-cache-fix.md](2026-09-18-account-edit-initial-balance-stale-cache-fix.md))
5. **日曆週檢視「今天」跳對週**(見
   [2026-09-18-calendar-week-view-today-jump-fix.md](2026-09-18-calendar-week-view-today-jump-fix.md))

## 改動檔案

- `lib/whats_new/whats_new_content.dart` — 新增 `'3.5.0'` key,含上述 5 筆
  `WhatsNewItem`。
- `lib/l10n/app_en.arb` / `lib/l10n/app_zh_TW.arb` — 新增對應的
  `whatsNew350*Title`/`...Desc` 十組 key(依 [L10n 政策](../../CLAUDE.md)只維護
  這兩個 arb,未動 `app_zh.arb`/`app_ko.arb`)。
- 已跑過 `flutter gen-l10n` 重新產生 `app_localizations*.dart`。

## 入口點

「我的」→「新功能！」,或是版本更新後首次啟動 App 自動彈出的公告視窗
(`lib/widgets/ui/whats_new_dialog.dart`)。5 項功能本身的入口點見各自
`docs/changes/` 文件。
