# 「新功能！」公告更新至 3.6.1(併入 3.6.0 精簡版)

## 背景

`pubspec.yaml` 已在 `0015698` 升到 `3.6.1+1`,但 `kWhatsNewContent` 沒有 `'3.6.1'` key,
所以升級後不會跳公告。`whats_new_dialog.dart` 只用 `PackageInfo.version` 查**目前版本**這一個
key,從 3.5.x 直接升到 3.6.1 的使用者看不到 `'3.6.0'` 的內容,所以把 3.6.0 的公告精簡後
併進 `'3.6.1'`,原本的 `'3.6.0'` key 移除(3.6.1 的 build 永遠查不到它)。

## 內容:9 筆(3.6.1 在前,3.6.0 精簡版在後)

3.6.0 的條目標題加上「(3.6.0)」後綴,讓使用者分得出哪些是上一版的內容。

| # | 項目 | 來源 | 入口 |
|---|---|---|---|
| 1 | Android 可以直接在 App 內更新 | [android-apk-self-update](2026-09-26-android-apk-self-update.md)(2430af8、31e87e3) | 啟動時自動彈出「發現新版本」;「我的 → 關於 → 檢查更新」;強制更新頁「立即更新」。僅 Android |
| 2 | AI 助手可以依帳戶查詢消費 | [ai-chat-account-name-query](2026-09-28-ai-chat-account-name-query.md)(d2162af) | 「明細」頁右上角 AI 助手圖示(需啟用 AI) |
| 3 | 其他修正 | 見下 | 無操作入口,升級後自動生效 |
| 4〜9 | 3.6.0 精簡版 | [whats-new-360](2026-09-26-whats-new-360.md) | 見該文件的入口表 |

第 3 筆合併了:分類顏色被 pull 覆蓋成灰色([category-color-pull-overwrite-fix](2026-09-29-category-color-pull-overwrite-fix.md))、
WebSocket 重連指數退避([ws-reconnect-storm-fix](2026-09-26-ws-reconnect-storm-fix.md))、AI 錯誤訊息改繁體
(ai-chat-account-name-query 的一部分;英文版沒寫這項,英文使用者看了沒意義)。

刻意沒列:Kotlin Gradle plugin 升級(fc60760,純建置工具)。

## 3.6.0 精簡方式

- 8 筆減為 6 筆:`AccountSwitcher`(帳戶明細頁 ▼ 切換)併進 `AccountGroup`;`NavMotion`(導覽列/記帳頁動畫)
  併進 `Fixes`(標題改為「其他改進與修正」)。這兩組 key 已從 arb 刪除。
- 其餘條目沿用 `whatsNew360*` key,只縮短文案:報表拿掉分頁逐一列舉、退款拿掉收支顏色方案、iOS 分享拿掉
  操作細節、授權金鑰拿掉版本過舊提示、修正拿掉「期間選單」與「Android 桌面圖示名稱」兩項。

## 改動檔案

- `lib/whats_new/whats_new_content.dart` — `'3.6.0'` 改為 `'3.6.1'`,內容如上。
- `lib/l10n/app_en.arb` / `lib/l10n/app_zh_TW.arb` — 新增 `whatsNew361*`(6 個),改寫 `whatsNew360*` 文案,
  刪除 `whatsNew360AccountSwitcher*`、`whatsNew360NavMotion*`。依 L10n 政策只維護這兩個 arb。
- 已跑 `flutter gen-l10n`。

## 入口點

「我的」→「新功能！」,或升級到 3.6.1 / 全新安裝後首次啟動自動彈出。
