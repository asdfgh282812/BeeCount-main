# 「新功能！」公告更新至 3.6.0

## 背景

`pubspec.yaml` 從 `3.5.7+1` 升到 `3.6.0+1`。3.5.7 之後的 commit(3b22ff6 授權金鑰 ~ d9bebd1 預設幣種 TWD)
都還沒發過公告。

`00b701d`(重構報表功能)曾在 `kWhatsNewContent` 放了一個 `'3.5.8'` key,但 pubspec 從來沒升到 3.5.8,
這個 key 永遠不會被 `whats_new_dialog.dart` 查到(它只用 `PackageInfo.version` 查目前版本)。這次把它
改名為 `'3.6.0'`,原本的 `whatsNew358StatisticsReport*` 文案改寫成 `whatsNew360StatisticsReport*`,
並把其他更新一併加進去。`'3.3.0'` / `'3.4.0'` / `'3.5.7'` 維持原樣(不會顯示,但留著無害)。

## 改動檔案

- `pubspec.yaml` — `version: 3.6.0+1`。
- `lib/whats_new/whats_new_content.dart` — `'3.5.8'` key 改為 `'3.6.0'`,1 筆擴充為 8 筆。
- `lib/l10n/app_en.arb` / `lib/l10n/app_zh_TW.arb` — 移除 `whatsNew358StatisticsReport*`(2 個),新增 `whatsNew360*`
  (16 個,8 組 Title/Desc)。依 L10n 政策只維護這兩個 arb。文案裡引用的按鈕/選單名稱已對照 arb 實際文字
  (`accountGroupCardTitle`、`accountGroupMergedBillingLabel`、`licenseSettingsTitle`、`appearanceSettings`、
  `appearanceColorScheme`)。
- 已跑 `flutter gen-l10n` 重新產生 `app_localizations*.dart`。
- `docs/changes/2026-09-25-statistics-report.md` — 「What's New 放在 `'3.5.8'`」那行改指向 3.6.0。

## 入口點

「我的」→「新功能！」,或升級到 3.6.0 / 全新安裝後首次啟動自動彈出(`lib/widgets/ui/whats_new_dialog.dart`)。
各項目自己的入口見上表。
